# 3D 퍼즐 섬

강윤지 담당. `salpim-prototype.html`의 섬 이미지를 참고해 만든 실제 Three.js 메시 모델입니다.
섬 장면에 이미지나 이미지 텍스처를 사용하지 않습니다.

## 확인

`npm run dev` 실행 후 `/island`에서 독립 화면을 확인합니다.
기존 등·하교 흐름의 마지막 단계에서도 `IslandBoard`를 통해 같은 3D 장면을 사용합니다.

- 드래그/한 손가락: 회전. 휠/두 손가락: 확대·축소.
- 시점 버튼 또는 캔버스에 포커스한 뒤 방향키, `+`, `-`, `Home` 사용.
- 아이 캐릭터는 처음부터 아이템을 들고 등장해 말풍선으로 배치할 곳을 물어봅니다.
- 섬의 빈 잔디를 클릭하면 캐릭터가 해당 자리까지 걸어간 뒤 말풍선으로 최종 확인합니다.
- 확정하면 캐릭터가 아이템을 내려놓고 “내일 또 봐!”라고 계속 인사합니다.
- 사용자가 말풍선의 `배치 종료`를 눌렀을 때만 인사가 끝나고 배치 파트가 종료됩니다.
- 해는 화면 왼쪽 위에 있는 것으로 계산합니다. 카메라 회전·높이 변화에 맞춰 실제 조명과 그림자를 갱신합니다.
- `우리 반 퍼즐`은 학기말에 아홉 조각이 결합되는 구조를 보는 미리 보기입니다.

## 구성

| 파일 | 역할 |
| --- | --- |
| `../IslandBoard.tsx` | 기존 등·하교 화면의 props를 유지하는 진입점 |
| `IslandExperience.tsx` | 독립/태블릿 UI와 제안·확정·인사 단계 관리 |
| `IslandScene.tsx` | WebGL 렌더러, 캐릭터 이동, 캐릭터 추적 말풍선, 카메라와 조명 |
| `islandModel.ts` | 섬 그룹(지형·자연물·배치 판정 면), 예시 선물과 아이 캐릭터 메시 |
| `islandTerrain.ts` | 퍼즐 외곽 아래의 저폴리 잔디 캡·흙층·암벽 지형 생성(시드 기반, 단일 geometry) |
| `puzzleGeometry.ts` | 퍼즐 외곽선, 학급 내 연결부 규칙, 배치 가능 영역 |
| `sunlight.ts` | 카메라 기준 왼쪽 위 광원과 그림자 방향 계산 |
| `types.ts` | 카메라/배치/퍼즐 타입 |

화면 스타일은 Tailwind로 작성했습니다. 정적 메시들은 재질별로 병합합니다.

## 섬 지형

- 윗면은 `createPuzzleShape` 외곽 그대로의 평평한 잔디(Delaunay 면 분할, 면마다 미세한 색 차이)이며, 클릭 판정은 기존 `item-placement-surface`가 그대로 담당합니다.
- 잔디 캡은 타일 폭의 약 1.9%로 얇고, 둥근 bevel과 살짝 튀어나온 가장자리, 일부 짧은 잔디 처짐이 있습니다.
- 흙층은 평균 약 2.1%의 얇은 띠로, 아래 경계가 부드럽게 흔들립니다.
- 암벽은 흙층 하단(ring 0)부터 약 0.99 → 0.96 → 0.83 배율의 불규칙한 ring 4개로 좁아지며, 둘레를 크기가 다른 암석 덩어리로 나눠 돌출·홈·처진 하단을 만듭니다. 상부를 거의 수직으로 두고 taper를 하단 ring에 모아 기본 시점에서 절벽이 잔디 가장자리 아래에 가려지지 않게 했습니다.
- 잔디·흙·암벽·절벽 바위는 정점 색상을 쓰는 flat-shaded 메시 하나(섬당 draw call 1개)이며, 시드 기반으로 생성 시 한 번만 계산합니다.
- 전체 측면 깊이는 타일 폭의 약 14–15%이고, 흙과 암벽은 모두 잔디 외곽 안쪽에 들어가 있어 퍼즐 결합 경계를 바꾸지 않습니다.
- 기본 시점은 약 24° 고도의 직교 카메라이며, 따뜻한 크림색 햇빛(화면 좌상단), 민트 hemisphere, 따뜻한 ambient, 카메라를 따라가는 청록색 fill light, Neutral tone mapping을 사용합니다.
화면이 보일 때 카메라나 배치 변화가 있는 경우에만 렌더링하며,
화면 해제 시 이벤트, 관찰자, GPU 리소스를 해제합니다.

## 모델 좌표와 퍼즐 결합

- X/Z가 지면 좌표이며 Y는 높이입니다. 배치 기준 높이는 `SURFACE_Y`입니다.
- 퍼즐 기본 폭은 `TILE_SIZE = 22`입니다. 이전 12 대비 면적 약 3.36배로, 하루 두 개씩 한 학기 동안 쌓일 아이템을 고려한 크기입니다.
- 기본 섬에는 집, 나무, 울타리와 길이 없고 작은 꽃, 돌, 풀만 17곳에 드문드문 배치됩니다.
- 북/동/남/서 연결부는 `-1`(홈), `1`(돌기), `0`(평면)입니다.
- `classroomEdges(row, col, rows, cols)`로 옆 조각과 상보적인 연결부를 생성합니다.
- 실제 외곽 곡선은 기본 간격에서 정확히 맞고, 화면에서는 경계가 보이도록 0.18 간격을 추가합니다.
- 최초 학생별 조각 배정 시 학급 격자와 위치를 고정해야 학기말에도 같은 윤곽을 유지할 수 있습니다.
- 섬 경계, 자연물의 작은 점유 영역, 이미 확정된 아이템이 새 아이템 배치를 제한합니다.

## 현재 범위와 연결할 부분

배치는 React 메모리 상태입니다. 최종 확인 후에는 현재 세션에서 위치를 수정할 수 없고,
새로고침하면 초기화되며 DB 저장은 아직 하지 않습니다.
학생명은 기본 예시인 민준이고, 우리 반 퍼즐도 실제 학급 데이터가 아닌 3×3 예시입니다.
기존 흐름에서 넘어온 획득 아이템은 이름을 유지하되 현재는 임시 별 모형으로 표현합니다.
실제 상담 아이템 모델 연동 시 `createGiftModel`을 `asset_catalog`의 signed GLB URL 로딩으로
교체하고, 모델 정규화와 학생별 좌표 조회/저장을 연결해야 합니다.

## 검증

Node 22.18 이상에서 추가 패키지 없이 도형/배치 테스트 실행:

```bash
node --test src/components/student/island/__tests__/puzzleGeometry.test.mjs src/components/student/island/__tests__/islandTerrain.test.mjs
npx tsc --noEmit
npx eslint src/components/student/island src/components/student/IslandBoard.tsx src/app/island
```

테스트는 다양한 학급 크기의 연결부, 가로/세로 인접 곡선의 실제 좌표 일치,
확장된 섬의 배치 범위, 자연물과 확정 아이템 충돌, 다양한 시점의 햇빛 및 그림자 방향을 확인합니다.
지형 테스트는 시드 결정성, 잔디 윗면과 퍼즐 외곽의 면적 일치, 닫힌 바깥 방향 메시와 측면 깊이 비율,
흙·암벽·바위가 잔디 외곽 밖으로 튀어나오지 않는지를 확인합니다.
