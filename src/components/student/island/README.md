# 3D 떠 있는 섬

강윤지 담당. `salpim-prototype.html`의 섬 이미지를 참고해 만든 실제 Three.js 메시 모델입니다.
섬 장면에 이미지나 이미지 텍스처를 사용하지 않습니다.

## 확인

`npm run dev` 실행 후 `/island`에서 독립 화면을 확인합니다.
기존 등·하교 흐름의 마지막 단계에서도 `IslandBoard`를 통해 같은 3D 장면을 사용합니다.

- 드래그/한 손가락: 회전. 휠/두 손가락: 확대·축소.
- 시점 버튼 또는 캔버스에 포커스한 뒤 방향키, `+`, `-`, `Home` 사용.
- 처음 들어오면 섬만 보입니다. 카메라가 옆·위에서 1.8초 동안 돌며 줌인해 기본 시점에 멈춥니다(방문당 한 번, 사용자가 조작하면 즉시 중단).
- 하단 툴바의 `아이템 배치하기`를 누르면 캐릭터가 아이템을 들고 “뿅” 등장합니다(0.4초 동안 크기 0 → 1.15 → 1, easeOutBack, 반짝이·먼지 파티클). 등장이 끝난 뒤에 말풍선이 뜨고, 그 전에는 섬 클릭을 받지 않습니다.
- 말풍선은 가로 172px로 캐릭터 머리 바로 위에 붙어 따라다니며, 단계가 바뀌어 새로 나타날 때마다 살짝 커지며 페이드 인합니다.
- 섬의 빈 잔디를 클릭하면 캐릭터가 해당 자리까지 걸어간 뒤 말풍선으로 최종 확인합니다.
- 확정하면 캐릭터가 아이템을 내려놓고 “내일 또 봐!”라고 계속 인사합니다.
- 사용자가 말풍선의 `배치 종료`를 눌렀을 때만 인사가 끝나고 배치 파트가 종료됩니다.
- 해는 화면 왼쪽 위에 있는 것으로 계산합니다. 카메라 회전·높이 변화에 맞춰 실제 조명과 그림자를 갱신합니다.
- `우리 반 섬`은 학기말에 아홉 개의 떠 있는 섬이 한 하늘에 모이는 모습을 보는 미리 보기입니다.

## 구성

| 파일 | 역할 |
| --- | --- |
| `../IslandBoard.tsx` | 기존 등·하교 화면의 props를 유지하는 진입점 |
| `IslandExperience.tsx` | 독립/태블릿 UI와 제안·확정·인사 단계 관리 |
| `IslandScene.tsx` | WebGL 렌더러, 인트로 카메라, 캐릭터 등장·이동, 캐릭터 추적 말풍선, 카메라와 조명 |
| `islandModel.ts` | 섬 그룹(지형·로우폴리 자연물), 예시 선물, 공용 `Sculpt`/팔레트 |
| `character.ts` | 관절이 있는 아이 캐릭터(포즈·숨쉬기·걷기·손 흔들기)와 등장 파티클 |
| `islandTerrain.ts` | 언덕 잔디 윗면, 흘러내리는 잔디 테, 흙·바위 지층, 절벽 돌·떠 있는 돌 생성(시드 기반, 단일 geometry), 깎인 돌 모양 `chisel` |
| `islandSky.ts` | 섬 아래·주변의 로우폴리 구름 |
| `placement.ts` | 시드별 타원 윤곽·언덕 높이, 자연물 배치, 배치 가능 영역 |
| `sunlight.ts` | 카메라 기준 왼쪽 위 광원과 그림자 방향 계산 |
| `types.ts` | 카메라/배치 타입 |

화면 스타일은 Tailwind로 작성했습니다. 정적 메시들은 재질별로 병합합니다.

## 섬 지형과 하늘

- 윤곽은 평균 반지름 `ISLAND_RADIUS = 14`의 타원(장축 +10%, 단축 −10%)에 시드별 저주파 조화파(±8% 안팎)를 더한 유기적 곡선입니다. 장축은 기본 카메라의 화면 가로 방향입니다.
- 윗면은 가장자리 높이 `SURFACE_Y`에서 완만한 언덕 3개와 낮은 돔이 솟습니다(최고 약 +1.6~2.0, 경사 0.4 미만). 언덕은 가장자리로 갈수록 0으로 줄어 테두리는 수평입니다. `layout.heightAt(x, z)`가 메시 정점과 정확히 같은 높이를 돌려주며, 자연물·아이템·캐릭터는 이 높이에 놓입니다.
- 잔디 lip·흙층·층 두께는 유지하고 암벽은 `rockCliff.ts`의 개별 돌 쌓기로 구성합니다. 어두운 단색 코어 앞에 각진 원형 7종을 InstancedMesh로 재사용하며, 돌마다 단색 instanceColor와 flatShading 조명만 사용합니다. 텍스처·vertex color 보간·displacement는 없습니다.
- 조절값: `ROCK_ROWS=4`, `ROCK_SIZE_RANGE=[1/8,1/3]`(암벽 높이 기준), `ROCK_SPACING=0.72`(작을수록 돌 수 증가), `ROCK_VARIANTS=7`, `ROCK_PALETTE`(5색). 민준이 조각은 경계 돌·이끼를 포함해 370개이며 실제 수는 `group.userData.rockStats.count`에서 확인합니다. `ROCK_SINGLE_EDGE=true`로 한쪽 긴 변 시제품을 재현할 수 있습니다.
- 배치 후 회전·스케일을 반영한 AABB의 네 모서리와 오목한 윤곽의 교차를 검사하고 안쪽으로 이동합니다. `node --test src/components/student/island/__tests__/rockCliff.test.mjs`는 20개 조각 × 두 모드의 모든 인스턴스 윤곽·바닥 깊이 및 재질을 검증합니다. 개인 섬의 구름과 하단 툴바 배경 그라데이션은 암벽을 가리지 않도록 제거했습니다.
- 층 사이 짧은 선반면은 밝은 색으로 칠해 지층 선이 보이게 했습니다. 모든 층은 같은 물결을 따라 오르내리고, 공통 반경 굴곡이 세로 절벽 능선을 만듭니다. 평면 셰이딩과 면별 명도 흔들림으로 로우폴리 느낌을 줍니다.
- 링 사이를 정점 수가 달라도 지퍼식으로 이어 붙여, 닫힌(watertight) 바깥 방향 메시 하나가 됩니다. 옆에는 작은 돌 3개가 떠 있고, 흙벽·윗 바위층(깊이 2.7~5.8)에는 반쯤 박힌 돌 9개가 튀어나와 있습니다. 돌은 모두 꼭짓점을 무작위로 민 저폴리 다면체입니다.
- 배경은 캔버스 뒤 CSS 하늘 그라데이션이고, `islandSky.ts`의 구름은 섬 아래·양옆에 둡니다. 구름은 raycast에서 제외합니다.
- 클릭은 지형 메시에 raycast하되 `SURFACE_Y` 이상(잔디 윗면)에 맞은 경우만 받습니다. 배치 표시 링은 맞은 면의 기울기에 맞춰 눕힙니다.
- 아이템은 가장자리에서 0.9 이상 안쪽이어야 합니다. 자연물은 각도·반지름 비율로 지정해 어떤 시드의 윤곽에서도 섬 안에 들어오고, 점유 면적은 20% 이하, 중앙 반지름 6.5 안은 모두 배치 가능합니다.
- 활엽수 2그루, 침엽수 4그루, 수풀 4개, 풀 1군락, 꽃 3군락, 바위 무리 3개를 가장자리에 둡니다. 키 큰 나무는 기본 카메라 반대편(150°~300°)에만 둡니다. 학급 모드에서는 학생 본인 섬(시드 17)에만 나무를 표시합니다.
- `layout.scatter`의 풀 다발·작은 꽃·자갈(시드당 약 120개)은 배치를 막지 않는 대신, 원래 배치할 수 없는 가장자리 띠(테두리에서 0.25~0.75 안쪽)와 자연물 점유 영역 안에만 놓입니다.
- 섬 윤곽만 둥글고, 위에 올라가는 자연물은 모두 `flatShading` 로우폴리입니다. 돌·수관·수풀은 Icosahedron/Dodecahedron을 `chisel`로 깎고, 침엽수는 7각 원뿔 3~4단, 활엽수는 기울어진 6각 줄기와 곁가지, 풀은 3각 원뿔 잎, 꽃잎은 납작한 팔면체입니다.

## 캐릭터

- 머리:몸 약 1:2.2(2.2등신). 몸통은 어깨가 넓고 허리가 좁은 타원 단면이고, 반팔·상완·팔꿈치·하완·손, 반바지·허벅지·무릎·종아리·신발로 나뉩니다.
- 관절(목, 어깨, 팔꿈치, 골반, 무릎)은 각각 병합된 부위 그룹이라 포즈와 애니메이션을 줄 수 있습니다. 기본 팔 자세는 몸 옆으로 약간 벌리고 팔꿈치를 살짝 굽힌 모양, 들기 자세는 두 손으로 화분 옆을 받칩니다.
- 서 있는 동안 2.6초 주기로 상체가 오르내리고 팔·머리가 미세하게 흔들립니다. 걸을 때는 다리(뒤쪽 무릎 굽힘)와 빈손일 때 팔이 번갈아 흔들리고, 작별 인사 때는 오른팔을 들어 손을 흔듭니다.
- `prefers-reduced-motion`이면 인트로·등장·숨쉬기·손 흔들기 없이 정지 자세로 보여 줍니다.

## 카메라

- 기본 시점은 방위 45°, 고도 30°의 직교 쿼터뷰입니다.
- 장면을 만들 때 실제 섬 정점을 기본 시점의 화면 축에 투영해 폭·높이를 잰 뒤, 섬이 캔버스 가로의 66%(학급 90%)를 채우도록 확대합니다. 세로가 먼저 부족하면 높이 84%(학급 86%)에 맞춥니다. 1344×760 섹션에서 가로 66%, 세로 82%입니다.
- 회전 중심은 섬 화면 높이의 가운데입니다. 세로 화면에서는 말풍선 공간을 위해 섬을 약간 아래에 둡니다.
- 데스크톱 섹션 높이는 두꺼운 섬이 가로 66%를 차지할 수 있도록 760px입니다(모바일 600px).
- 기본은 demand rendering입니다. 카메라 조작·인트로·캐릭터가 섬에 나와 있는 동안(숨쉬기 애니메이션)만 매 프레임 그립니다. ResizeObserver/IntersectionObserver, 화면 숨김 처리 및 GPU 리소스 해제를 유지합니다.

## 모델 좌표와 학급 배치

- X/Z가 지면 좌표이며 Y는 높이입니다. 각도는 +X에서 +Z 방향으로 잽니다.
- 학생 섬의 모양은 시드로만 결정됩니다. 최초 학생별 섬 배정 시 시드를 고정해야 학기말에도 같은 윤곽을 유지합니다.
- 학급 보기는 3×3, 간격 33으로 섬을 띄우고 섬마다 높이를 조금씩 다르게 둡니다.
- 섬 경계, 자연물의 작은 점유 영역, 이미 확정된 아이템이 새 아이템 배치를 제한합니다.

## 현재 범위와 연결할 부분

배치는 React 메모리 상태입니다. 최종 확인 후에는 현재 세션에서 위치를 수정할 수 없고,
새로고침하면 초기화되며 DB 저장은 아직 하지 않습니다.
학생명은 기본 예시인 민준이고, 우리 반 섬도 실제 학급 데이터가 아닌 3×3 예시입니다.
기존 흐름에서 넘어온 획득 아이템은 이름을 유지하되 현재는 임시 별 모형으로 표현합니다.
실제 상담 아이템 모델 연동 시 `createGiftModel`을 `asset_catalog`의 signed GLB URL 로딩으로
교체하고, 모델 정규화와 학생별 좌표 조회/저장을 연결해야 합니다.

## 검증

Node 22.18 이상에서 추가 패키지 없이 도형/배치 테스트 실행:

```bash
node --test src/components/student/island/__tests__/placement.test.mjs src/components/student/island/__tests__/islandTerrain.test.mjs
npx tsc --noEmit
npx eslint src/components/student/island src/components/student/IslandBoard.tsx src/app/island
```

배치 테스트는 시드별 유기적 타원 윤곽, 완만한 언덕과 수평 테두리, 배치 범위와 잔디 테 제외,
자연물과 확정 아이템 충돌, 흩뿌린 풀·꽃·자갈이 배치 가능한 자리를 차지하지 않는지,
다양한 시점의 햇빛 및 그림자 방향을 확인합니다.
지형 테스트는 시드 결정성, 닫힌 바깥 방향 메시(모든 모서리가 반대 방향 면과 짝을 이룸),
윗면 정점이 `heightAt`과 일치하고 윤곽 면적을 덮는지, 잔디 테의 돌출과 흙벽 두께, 바위가 끝으로 좁아지는지 확인합니다.
