# System Prompts

각 AI 기능별 system prompt를 이 폴더에 파일로 분리해서 관리합니다 (route.ts에 문자열로 박아넣지 말 것 — 버전 관리·리뷰가 안 됨).

- `chat.ts` — 등/하교 꼬리질문 대화 (이유민)
- `item-inference.ts` — 상담 전문 → 자유로운 소재·의미·크기 추론 (강윤지)
- `comment-draft.ts` — 교사 코멘트 초안 (김현우)
- `daily-analysis.ts` — 아이 상세 AI 분석 (김현우)
- `teacher-agent/` — 협진 챗봇 3개 system prompt (이지현)
