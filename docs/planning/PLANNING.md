# [학생 화면] — 등교 흐름 (5단계)

## 1단계: 교사 코멘트 확인
- AI가 초안을 잡고 교사가 수정·승인한 피드백 카드가 화면에 표시됨
- 학생이 읽고 "다음으로" 터치 → 2단계로

## 2단계: 색 선택 (신호등)
- 4가지 색을 큰 원형 버튼으로 화면에 표시
- 터치 한 번으로 선택

| 색   | 의미                           |
| ---- | ------------------------------ |
| 초록 | 기분 좋아요                    |
| 노랑 | 그저 그래요                    |
| 빨강 | 오늘은 좀 기분이 안 좋아요     |
| 남색 | 오늘 나 조금 혼자 있을 시간이 필요해요 |

## 3단계: AI 꼬리 질문 (색에 따라 분기)

색을 선택하면 AI가 해당 색에 맞는 질문을 건넴

| 색   | AI 첫 질문 예시                              | 추가 대화     |
| ---- | -------------------------------------------- | ------------- |
| 초록 | "뭐가 좋았어? 자랑하고 싶은 일 있어?"       | 선택적 (짧게) |
| 노랑 | "왜 기분이 좀 그런지 얘기해줄 수 있어?"     | 1~2턴         |
| 빨강 | "무슨 일 있었어? 말해줄 수 있으면 얘기해봐" | 최대 2턴      |
| 남색 | 질문 없음. "알겠어. 오늘은 그냥 둘게. 필요하면 언제든 눌러." → 대화 종료 | —  |

- AI 추가 질문 여부: AI가 판단. 아이가 회피 신호 2회 또는 2턴 도달 시 무조건 종료
- 남색은 교사 화면에만 조용히 표시됨 (아이에게 말 걸지 않음)

## 4단계: 아이템 생성
- 3단계 대화가 끝나면 AI가 대화 내용에서 대표 사물 1개를 추론
- 추론 결과를 `item_candidates`에 원본 `session_id`·`message_id`와 함께 저장
- 저장된 후보를 바탕으로 에셋 생성 담당자가 아이템 에셋 생성을 진행
- 아이템은 감정이 아닌 **사물** 기반 (조작 동기 없음)

| 아이 발화 예시          | 생성 아이템  |
| ----------------------- | ------------ |
| "축구했어요"            | ⚽ 축구공   |
| "동생이랑 놀았어요"     | 🧒 사람     |
| "급식에 돈까스 나왔어요" | 🍱 음식    |

- 화면에 아이템 미리보기 + "섬에 배치하러 가기" 버튼
- 등교 1개 + 하교 1개 = 하루 총 2개 (누적만, 삭제 없음)

## 5단계: 섬에 배치
- 나만의 섬 화면으로 이동
- 생성된 아이템을 섬 위에 원하는 위치에 터치로 배치
- 배치 완료 → 등교 체크인 끝 🎉
- 아이템은 누적만 됨 (삭제 없음, 스트릭 소멸 없음)

# [학생 화면] — 하교 흐름 (3단계)

## 1단계: 색 선택
- 등교와 동일한 4색 신호등

## 2단계: AI 질문 (고정)
- "오늘 학교에서 털어놓고 싶은 일 있어?" (매일 동일 — 갈등 포착 창구)
- 아이가 이야기하면 AI가 1~2턴 반응
- 남색 선택 시 → 대화 없이 조용히 마무리

## 3단계: 아이템 생성 + 섬 배치
- 등교와 동일한 흐름 (하교분 아이템 1개 추가)

---

# [공통 원칙]
- 교사 코멘트는 등교 시에만 표시 (하교에는 없음)
- 아이 면담 신청: 대화 마무리 후 "선생님께 직접 얘기하고 싶어요" 버튼 선택 가능
- 전체 소요 시간: 등교 30초 / 하교 30초 목표

# [교사 화면] — 탭 구조 (4개)

탭: **대시보드 / 아이 상세 / 학생관찰일지 / 학부모상담기록**  
첫 화면은 대시보드.

---

## 탭 1. 대시보드

### 상단: 오늘의 색 현황
- 등교 색 집계 (초록 N / 노랑 N / 빨강 N / 남색 N)
- 하교 색 집계 (동일 구조)

### 섹션 순서 (위→아래 스크롤)

| 순서 | 섹션             | 내용 요약                                               |
| ---- | ---------------- | ------------------------------------------------------- |
| 1    | 아침 브리핑      | 오늘 살펴볼 아이 3명 + 한마디 돌려줄 아이 3명           |
| 2    | 관계 지도        | 발화에서 추출한 아이들 간 언급 관계망                   |
| 3    | 갈등 기록        | 최근 갈등 발생 목록, 양측 진술 나란히 보기              |
| 4    | 패턴 경고        | 요일·시간표 교차 이상징후 (예: 체육 있는 날 갈등 3회)   |
| 5    | 오늘의 교실      | 학급 전체 등교→하교 색 변화 (집단 분위기 파악)          |
| 6    | 감정 어휘 성장   | 월별 아이별 감정 어휘 종류 증가 추이 그래프             |

---

## 탭 2. 아이 상세

### 진입 화면: 자리 배치도
- 20명의 자리를 교실 배치 그대로 표시
- 각 자리에 아이 이름 + 오늘 등교 색 표시
- 자리 클릭 → 해당 아이 상세 페이지로 이동

### 아이 상세 페이지

**상단: 날짜 선택**
- 작은 달력으로 날짜 선택 가능
- 기본값: 당일

**본문: 선택된 날짜의 기록**
- 등교 신호등 색 + 하교 신호등 색
- 등교 AI 대화 전문 (질문·답변 텍스트)
- 하교 AI 대화 전문 (질문·답변 텍스트)
- AI 짧은 분석 (당일 대화 기반, 1~3문장)

**하단: 교사 코멘트 작성**
- AI가 당일 대화 기반으로 초안 자동 작성
- 교사가 읽고 수정 후 저장
- 저장된 코멘트는 **다음날 등교 시 해당 아이에게 전달**
- 자동 발송 없음 — 교사가 저장해야만 전달됨

---

## 탭 3. 학생관찰일지

> 교사의 일상적인 관찰·사건 기록 공간. 법적 방어를 위한 데이터 무결성 보장.

- **게시판 형태** (목록 → 상세)
- **글쓰기** 가능, **수정 불가** (무결성 — 추가 전용)
- 모든 글에 **서버 타임스탬프** 자동 부여
- 작성 시 **관련 아이 태그** 기능 (`@김민준` 형태)
  - 태그된 아이 기준으로 필터링·검색 가능
- **검색**: 키워드 / 날짜 범위 / 아이 이름으로 검색

---

## 탭 4. 학부모상담기록

> 학부모와의 상담 내용 보존. 데이터 무결성 보장.

- **게시판 형태** (목록 → 상세)
- **글쓰기** 가능, **수정 불가** (무결성 — 추가 전용)
- 모든 글에 **서버 타임스탬프** 자동 부여

**상담 자료 추출 기능**
- 글 작성 시 아이 이름 클릭 → 해당 아이의 누적 데이터를 파일로 생성
  - 포함 내용: 신호등 색 이력, 등하교 대화 전문, AI 분석, 학생관찰일지에 태그된 항목
- 학부모 상담 자리에서 근거 자료로 활용
- 구체적인 정보를 학부모에게 전달하기 위한 목적
