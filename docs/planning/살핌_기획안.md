# 0. 타겟

**초등학교 3~4학년 담임 교사.** 핵심 페르소나는 **3학년**입니다.

|      |                                                                      |
| ---- | -------------------------------------------------------------------- |
| 아이 | 만 8~10세. 글은 쓰지만 매일 쓰기는 부담. 또래 갈등이 본격화되는 시기 |
| 교사 | 담임이 대부분을 봄. 정서부터 학습까지 혼자 담당                      |
| 기기 | **디벗(교육용 패드) 1인 1대.** 3~4학년부터 보급, 점차 확대 중        |
| 동의 | 만 14세 미만 → **보호자 동의 100% 필수**                             |

## 왜 3~4학년인가

저학년(1~2학년)을 검토했으나 **기기가 없다는 물리적 제약**이 유일하게 설계로 우회할 수 없는 문제였습니다.

|             | 1~2학년 (공용 기기)     | **3~4학년 (디벗)**           |
| ----------- | ----------------------- | ---------------------------- |
| 입력 방식   | 순차 · 문 앞에서 줄서기 | **28명 동시, 자리에 앉아서** |
| 소요 시간   | 3분 30초                | **30초**                     |
| 본인 확인   | 사진 타일 터치 필요     | **불필요** — 개인 기기       |
| 교사 개입   | 줄 관리 필요            | **없음**                     |
| 실제 파일럿 | 불가                    | **가능**                     |

그리고 이 학년을 고르면 세 가지가 따라옵니다.

- **또래 갈등이 본격화되는 학년**입니다. 인터뷰에서 확인된 최대 기록 업무가 갈등입니다
- **4학년은 정서·행동특성검사 대상 학년**입니다. "연 1회 검사를 매일 30초로 대체한다"는 논리가 바로 그 학년에서 성립합니다
- **디벗은 확대 중**입니다. 시간이 우리 편이고, 보급이 내려가면 1~2학년으로 확장됩니다

> **1차 타겟은 3~4학년입니다. 1인 1기기가 보급된 학년이기 때문입니다.**
> 제품이 푸는 문제는 학년에 종속되지 않습니다 — 기기 보급이 확대되는 대로 아래위로 확장합니다.

## "글을 못 쓴다"가 아니라 "매일 쓸 수는 없다"

중학년은 글을 씁니다. 그래서 음성의 근거를 다시 세웁니다. 근거는 인터뷰 안에 있었습니다.

> "고학년도 **일주일에 1~2회** 일기 써서 감정이나 경험을 털어놓고, 제가 거기에 손으로 댓글 달아서 피드백해주는데 라포 형성에 굉장히 큰 도움이 됩니다."

|           | 일기         | 30초 음성  |
| --------- | ------------ | ---------- |
| 빈도      | **주 1~2회** | **매일**   |
| 아이 부담 | 큼           | 작음       |
| 교사 부담 | 손댓글 28개  | **원터치** |
| 톤 정보   | 없음         | **남음**   |
| 기준선    | 안 생김      | **생김**   |

살핌은 새로운 활동을 도입하라는 제안이 아닙니다. **이미 하고 계신 일기와 손댓글을 매일 가능하게 만드는 것**입니다.

# 1. 현장 인터뷰에서 확인한 것

초등 담임 교사 인터뷰(2026-09-12)에서 나온 내용입니다. 이 기획안의 주요 결정은 대부분 여기서 나왔습니다.

## 확인된 가설

| 우리 가설                   | 현장                                                                |
| --------------------------- | ------------------------------------------------------------------- |
| 기록이 법적 방어의 핵심     | **"적자생존 — 기록을 적은 자만이 살아남는다"** 학교에서 통용되는 말 |
| 기록 형식의 증거력이 불안정 | 수기·한글·나이스 모두 **"된다 안 된다 의견이 다 다름"**             |
| 지금은 사건 기반 기록       | **"큰 사건이 있는 경우, 문제행동 아동의 경우만 기록"**              |
| 기존에 색 활동을 한다       | **칠판 신호등 + 자석으로 이름 옮기기**                              |
| 교사 대응 기록이 필요       | "교사가 어떻게 대응했는지 기록할 수 있으면 좋겠고"                  |
| 패턴 탐지가 가치            | "아이의 감정 패턴을 찾아내기"                                       |

## 우리가 몰랐던 것 — 여섯 가지

**① 최대 기록 업무는 감정이 아니라 갈등입니다.**

> "가장 큰 기록 업무는 아이들끼리 갈등 있었는지. 갈등이 있어도 **교실에서 말 안 하고 집 가서 말해서** 부모님이 교사는 알고 있었냐는 식으로 나올 때가 많음."

→ 갈등을 1급 객체로 승격. 그리고 **하교 발화가 이 상황을 앞에서 막는 유일한 창구**입니다.

**② 색 신호등에 네 번째 색이 있습니다.**

> "기분 좋으면 초록, 그저 그러면 노랑, 오늘 좀 기분이 안 좋으면 빨강, **오늘 나 조금 혼자 있을 시간이 필요하면 남색**"

→ 남색은 좋다-나쁘다 척도 위의 값이 아니라 **요청**입니다. 별도로 다뤄야 합니다.

**③ 아이들은 자석으로 이름을 옮깁니다.**

→ 표정 5개를 새로 배우게 할 이유가 없습니다. 이미 몸에 익은 동작을 그대로 씁니다.

**④ 3~4학년은 디벗 1인 1대입니다.**

→ 타겟과 운영 설계가 여기서 결정됐습니다.

**⑤ 나이스는 2년 전 억 단위로 리뉴얼됐습니다.**

→ **연동하지 않습니다.** 우리 자리는 나이스가 담지 못하는 영역입니다.

**⑥ 그리고 가장 중요한 것 — 교사가 느끼는 건 위험이 아니라 죄책감입니다.**

> "보통의 예쁜 평범한 아이들의 감정을 더 살펴주지 못하고 에너지 써주지 못하는 **죄책감**이 대부분의 선생님들이 굉장히 큼. **금쪽이에게 에너지를 다 뺏겨서 우리 반 유니콘에게 긍정적인 피드백을 주지 못하는데.**"
>
> "기록하고 교사가 클릭? AI 이용해서 짧게 빠르고 간단하게 긍정 피드백 줄 수 있으면 이 부분도 좀 해결될 것 같음"

→ **제품의 프레임이 바뀌었습니다.**

|           | 기존 프레임                | 현재 프레임                                   |
| --------- | -------------------------- | --------------------------------------------- |
| 문장      | "놓친 아이를 찾아드립니다" | **"모든 아이에게 한 마디씩 돌아가게 합니다"** |
| 감정      | 불안 · 방어                | **해소 · 돌봄**                               |
| 구매 동기 | 사고가 날까 봐             | **매일 느끼는 미안함이 매일 해소돼서**        |

그리고 해법까지 교사가 직접 제시했습니다. 그것이 [유니콘 피드백](#63-유니콘-피드백--이-제품의-중심)입니다.

## 아직 확인이 필요한 것

- 3~4학년도 감정 신호등(자석) 활동을 하는가 — 저학년 활동일 가능성
- 중학년 아이들이 자기 기분을 반 전체에 공개하는 걸 꺼리지 않는가

# 2. 문제

## 살핌은 남지 않는다

> **교사는 매일 아이의 마음을 살핍니다. 그런데 그 살핌은 어디에도 남지 않습니다.**

남지 않는 이유는 교사가 게을러서가 아닙니다. **구조적으로 불가능합니다.** 20명의 얼굴을 보면서 동시에 20명분을 적을 수는 없습니다.

| 숫자       |                                                          |
| ---------- | -------------------------------------------------------- |
| **10,080** | 20명 × 하루 2회 × 180일 = 한 학급의 1년치 발화 수        |
| **1회**    | 현재 학생 정서·행동 상태를 공식적으로 확인하는 연간 횟수 |
| **0건**    | 그 사이 179일 동안 남는 개별 기록                        |

## 정량 업무에는 시스템이 있고, 정성 업무에는 없다

|           | 정량 업무                     | 정성 업무                        |
| --------- | ----------------------------- | -------------------------------- |
| 무엇      | 출결 · 성적 · 건강기록 · 공문 | **이 아이가 지금 어떤 상태인가** |
| 시스템    | 나이스                        | **없음**                         |
| 저장 위치 | 전산                          | **교사 개인의 기억**             |
| 인계      | 됨                            | **안 됨 — 학년이 바뀌면 리셋**   |
| 증명      | 됨                            | **안 됨**                        |

> **교사가 가장 많은 시간을 쓰는 일이, 가장 기록되지 않는 일입니다.**

## 네 개 층

| 층  |                             | 내용                                                                                                            |
| --- | --------------------------- | --------------------------------------------------------------------------------------------------------------- |
| 1   | **시점이 어긋난다**         | 사건은 복도·급식 줄·체육 시간에 일어나고, 기록할 시간은 방과 후입니다. **말할 시간은 있고, 쓸 시간이 없습니다** |
| 2   | **무엇을 적을지 모른다**    | 사실·관찰·해석·조치가 분리돼야 하는데, **말할 때는 그렇게 나오지 않습니다**                                     |
| 3   | **눈에 띄는 아이만 남는다** | 기록은 소리를 내는 아이를 남깁니다. 그리고 **나머지 아이들에 대한 죄책감이 남습니다**                           |
| 4   | **남겨도 신뢰가 안 된다**   | 흩어지고, 사후 작성이 가능하고, 방어적으로 쓰여 "특이사항 없음"만 쌓입니다                                      |

## 그 결과 세 가지가 동시에 발생한다

|          |                                                                                                                                                         |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **아이** | 갈등이 있어도 교실에서 말하지 않고 집에 가서 말합니다. 다음 날 부모가 전화합니다                                                                        |
| **상담** | 학부모 상담에서 교사가 근거로 댈 수 있는 것이 **인상과 기억**뿐입니다                                                                                   |
| **교사** | 일이 터지면 이 질문을 받습니다 — **알고 있었습니까. 관찰했습니까. 기록했습니까.** 그리고 평소에는, 조용한 아이들에게 아무것도 못 해준 미안함이 남습니다 |

# 3. 두 개의 명제

> **① 기록은 '쓰는 일'이어서 실패했다.** 말하기로 바꾸면 된다.
>
> **② 기록은 눈에 띄는 아이만 남긴다.** 그 결과는 위험이 아니라 **죄책감**이다.

첫 번째가 기록 문제를 풀고, 두 번째가 **구매 동기**를 만듭니다.

## 왜 지금 AI인가

이 문제는 기록 양식이 부족해서 생긴 게 아닙니다. **기록하는 행위 자체가 관찰을 방해했기 때문에** 생겼습니다. 그래서 더 좋은 엑셀 서식으로는 풀리지 않습니다.

연 1만 건의 발화는 사람이 읽고 정리할 수 있는 양이 아닙니다. 아이의 말을 받아 적고, 1년치를 누적해 변화를 읽고, 교사에게 **결론이 아니라 볼 곳**만 건네고, **20명 전원에게 한 마디씩 돌려주는 일** — 이 네 가지가 동시에 가능해진 것이 지금입니다.

# 4. 해결 구조

## 두 개의 입력 채널 — 역할이 다르다

|           | 아이 발화                             | 교사 발화                |
| --------- | ------------------------------------- | ------------------------ |
| 커버리지  | **전원 · 매일 · 무편향**              | 사건 중심 · 선택적       |
| 담는 것   | 속마음, 집에서의 일, 교사가 없는 자리 | 맥락, 관찰, 조치         |
| 증거 역할 | **사실관계 · 기준선**                 | 의무 이행                |
| 없으면    | 기준선이 사라진다                     | 무엇을 했는지가 사라진다 |

아이 채널은 사각지대 문제의 **탐지가 아니라 해소**입니다 — 20명 전원이 매일 입력하면 사각지대가 애초에 생기지 않습니다.

## 하루에 쓰는 시간

| 아이            | 교사         | 기록               |
| --------------- | ------------ | ------------------ |
| **30초**        | **1분**      | **0초**            |
| 색 3초 + 한마디 | 읽고, 누르기 | 확인하면 자동 봉인 |

기존 감정 신호등 활동을 **대체하지 않고 그대로 감쌉니다.** 칠판 자석을 디벗으로 옮기는 것뿐이고, 달라지는 건 그 활동이 사라지지 않고 쌓인다는 점입니다.

# 5. 아이 쪽 설계

## 5.1 흐름 — 색 먼저, 그다음 대화

```
[등교]
 ① 색 신호등 — 3초, 전원 100%
      초록 ─→ "좋다! 뭐가 좋았어?"   짧게 한마디 (선택)
      노랑 ─→ 한마디 (선택)
      빨강 ─→ AI 대화 1~2턴          ← 여기에 자원을 씁니다
      남색 ─→ AI 물러남 · 교사에게만 표시

[하교]
 ② 색 신호등 — 3초
 ③ "오늘 학교에서 털어놓고 싶은 일 있어?"   ← 갈등 포착 창구
```

대부분의 아이는 **10초**, 빨강인 아이만 **40초**입니다. 디벗이라 20명 동시이므로 학급 전체가 1분 안에 끝납니다.

### 색을 먼저 받는 이유 세 가지

- **참여율 100%가 보장됩니다.** 말하기 싫은 날에도 색은 고릅니다. **기준선이 끊기지 않습니다**
- **색이 분기 조건입니다.** 별도 계산이 필요 없습니다
- **색이 대화의 컨텍스트가 됩니다.** _"오늘 빨강이네. 무슨 일 있었어?"_ 와 _"오늘 어땠어?"_ 는 답변의 질이 다릅니다

## 5.2 네 개의 색 — 남색은 척도가 아니다

| 색          | 의미                                       | 처리                      |
| ----------- | ------------------------------------------ | ------------------------- |
| 🟢 초록     | 기분 좋아요                                | 척도 값                   |
| 🟡 노랑     | 그저 그래요                                | 척도 값                   |
| 🔴 빨강     | 오늘 좀 기분이 안 좋아요                   | 척도 값 · **대화로 분기** |
| 🔵 **남색** | **오늘 나 조금 혼자 있을 시간이 필요해요** | **척도 밖 · 별도 트랙**   |

남색은 나쁜 상태가 아니라 **요청**입니다. 세 가지를 반드시 지킵니다.

- **기준선 계산에서 분리합니다.** 남색을 낮은 값으로 처리하면 지표가 오염됩니다
- **AI가 대화를 걸지 않습니다.** 혼자 있고 싶다고 한 아이에게 말을 거는 건 모순입니다

  > _"알겠어. 오늘은 그냥 둘게. 필요하면 언제든 눌러."_

- **교사에게만 조용히 표시합니다.** 오늘 이 아이에게 말 걸지 않는 게 낫다는 정보입니다

이 설계가 세 가지를 동시에 합니다. 아이는 **자기 요청이 받아들여지는 경험**을 하고, 교사는 행동 가능한 정보를 얻고, 우리 원칙(**AI가 입을 닫는 것도 기능**)과 일치합니다.

## 5.3 인터랙션 — 자석을 그대로 옮긴다

칠판에서 하던 동작을 화면에서 그대로 합니다. **자기 이름 타일을 색 칸으로 드래그.** 새로 배울 게 없고, 본인 확인과 상태 입력이 한 동작으로 합쳐집니다.

**공개/비공개는 교사 설정으로 둡니다.** 칠판 자석판은 반 전체가 보는 공개 방식이었습니다. 디지털로 옮기며 비공개로 바꾸면 교실 운영이 달라지므로, 교사가 고르게 합니다. 단 **발화 내용은 항상 비공개**입니다.

## 5.4 질문 설계 — 인터뷰에서 그대로 가져옴

|                      | 질문                                                                          |
| -------------------- | ----------------------------------------------------------------------------- |
| **등교 앵커 (고정)** | 색 신호등                                                                     |
| 등교 보조 (로테이션) | 어제 기억에 남는 일 있어? / **어제 자랑하고 싶은 일 있었어?** / 어제 잘 잤어? |
| **하교 앵커 (고정)** | 색 신호등                                                                     |
| **하교 보조 (고정)** | **오늘 학교에서 털어놓고 싶은 일 있어?**                                      |

하교 보조 질문은 로테이션하지 않습니다. **갈등을 잡는 유일한 창구**라 매일 같아야 합니다.

"어제 자랑하고 싶은 일"은 긍정 발화를 유도하는 질문입니다. 유니콘 피드백의 재료가 여기서 나옵니다.

## 5.5 보상 설계

### 절대 규칙: 보상은 "말했다는 행위"에만 붙는다

> **보상이 발화 내용에 연동되면 데이터가 오염됩니다.** 아이가 "좋은 기분을 말해야 보상받는다"고 느끼는 순간 이 제품은 죽습니다.

| ✅ 보상해도 되는 것     | ❌ 절대 연동 금지                                   |
| ----------------------- | --------------------------------------------------- |
| 오늘 말했다 (참여 자체) | 긍정적 감정을 말했다                                |
| 매일 쌓인다             | 길게 말했다 → 꾸며내기 유발                         |
|                         | 아이들 간 순위·비교                                 |
|                         | **스트릭 소멸** — 결석·아픈·힘든 아이를 벌하는 구조 |

블록은 누적만 되고 **절대 사라지지 않습니다.**

### 보상

|      | 무엇                                                                                       | 왜                                      |
| ---- | ------------------------------------------------------------------------------------------ | --------------------------------------- |
| 개인 | **나의 섬** — 그날 발화에 관련된 아이템을 생성, 매일 블록 두개를 섬에 배치하게 됨. 나만 봄 | 비교 불가 → 조용한 아이가 소외되지 않음 |

### 블록은 감정이 아니라 사물에서 뽑는다

```
"축구했어요"        → 축구공 블록
"동생이랑 놀았어요"  → 사람 블록
"급식에 돈까스"      → 음식 블록
```

감정을 블록에 반영하면 아이가 블록을 얻으려고 감정을 조작합니다. **사물은 조작 동기가 없습니다.** 그리고 블록 모음이 곧 **그 아이의 1년 관심사 지도**가 되어 상담 자료와 유니콘 피드백의 재료가 됩니다.

### 진짜 보상은 반응입니다

블록보다 강한 참여 동기는 **말했더니 답이 온다**는 경험입니다. 유니콘 피드백이 그 역할을 합니다. 보상 시스템은 보조입니다.


**왼쪽만 있는 도구는 방어 도구입니다. 오른쪽이 있어야 돌봄 도구가 됩니다.** 그리고 오른쪽이 교사가 매일 느끼는 미안함을 매일 해소합니다.

## 6.4 갈등 기록 — 최대 기록 업무

> "갈등이 있어도 교실에서 말 안 하고 집 가서 말해서 부모님이 교사는 알고 있었냐는 식으로 나올 때가 많음"

하교 질문이 이 상황을 앞에서 막습니다. 그리고 갈등이 발생하면 **진술을 판정하지 않고 나란히 보존**합니다.

> **9월 18일 · 급식 시간**
> **민준**: "서연이가 먼저 밀었어요."
> **서연**: "민준이가 제 자리에 앉아서 비키라고 했는데 안 비켰어요."
> **교사 관찰**: 부딪히는 소리를 들었고, 서연이 울고 있었다.
>
> ⚠ 세 진술이 서로 다릅니다. 판단 전에 양쪽 원본을 확인하세요.

AI는 누가 맞는지 판정하지 않습니다. **진위 판정 기록은 공격거리가 되고, 양측 원본 보존은 방어가 됩니다.**

## 6.7 관계 지도

아이들 발화에서 서로의 이름이 언급되는 빈도로 관계망을 만듭니다. 누적 데이터가 있어야만 가능하고, 교사가 손으로는 못 만듭니다.

| 신호              |                                      |
| ----------------- | ------------------------------------ |
| **언급 0회**      | 3주간 아무도 이름을 부르지 않은 아이 |
| **부정 맥락 80%** | 언급은 많은데 갈등                   |
| **폐쇄 그룹**     | 서로만 언급, 외부 언급 0             |

싸우는 아이는 눈에 띄지만 **아무 관계도 없는 아이**는 보이지 않습니다. 갈등 예방의 핵심 화면입니다.

**지킬 것:** 아이들에게 절대 보이지 않습니다. 관계를 평가하지 않고 "언급 0회"라는 사실만 표시합니다. 학부모에게도 나가지 않습니다.

# 7. 확장 기능

## 7.1 패턴 경고 — 요일·시간표 교차 ○

> "월요일마다 폭발하거나, 시험 있기 전에 감정 쳐지거나, **체육 있는 날 꼭 싸우는** 패턴을 보이는 아이들이 있음"

우리에게 없던 축입니다. 시간표·일정과 감정 데이터를 교차합니다.

> **오늘 3교시 체육입니다.**
> 민준이는 체육이 있는 날 갈등 기록이 3회 있었습니다. (9/3, 9/10, 9/17)

예측이 아니라 **사실 제시**라 판정 회피 원칙에 어긋나지 않습니다. 구현도 간단합니다(요일·시간표를 축으로 교차 집계).

## 7.2 오늘의 교실 — 아이가 아니라 환경을 진단 ○

28명의 등교→하교 변화를 합치면 그날 교실에 무슨 일이 있었는지가 나옵니다. 수요일에 22명 중 17명이 낮아졌다면 그날 뭔가 있었던 겁니다.

**"이 아이가 문제"에서 "이 시간이 문제"로 프레임이 바뀝니다.** 개인을 들여다보지 않고 개입할 수 있는 유일한 화면이라 윤리적으로 가장 안전하고, 이미 있는 데이터의 합계라 구현이 가장 쉽습니다.

## 7.3 감정 어휘 성장 — 측정 가능한 교육 성과 ○

|                          | 3월 | 7월 | 12월 |
| ------------------------ | --- | --- | ---- |
| 민준이 쓴 감정 어휘 종류 | 3개 | 7개 | 14개 |
| 학급 평균                | 4.2 | 8.1 | 15.6 |

자기 감정을 언어로 말하는 것은 정서 교육의 핵심 목표인데 **측정할 방법이 없었습니다.** 학교가 돈을 내는 이유가 "교사 편의"가 아니라 **"교육 효과를 처음으로 측정 가능하게 만들었다"**가 됩니다.

# 8. 기술 설계

## 8.1 음성은 저장하지 않습니다

아동 음성은 생체정보에 준합니다. 유출 시 음성 합성·사칭 등 악용 경로가 실재하고, 학교·교육청 심의와 보호자 동의의 난이도가 완전히 달라집니다.

```
음성 수신
  ↓ 처리 시점에 한 번만
  ├─ 전사 텍스트          → 저장
  ├─ 파생 수치 (prosody)  → 저장
  │    발화 길이 12.4초
  │    첫 응답 지연 3.1초
  │    무음 구간 2회 (1.8s, 1.3s)
  │    성량 상대값 −30% (본인 평균 대비)
  │    발화 속도 2.1음절/초
  └─ 원본 음성            → 즉시 파기
```

**파생 수치는 목소리가 아니라 측정값입니다.** 개인을 식별할 수 없습니다. 그런데 교사 화면에 보여주던 근거는 전부 이 숫자였습니다 — _"첫 응답 전 3.1초 침묵, 성량 30% 감소"_. **차별점이 유지됩니다.**

### 정확한 문구

> **아이의 음성은 처리를 위해 전송되지만, 어디에도 저장되지 않습니다.**
> 전사와 측정값만 남고, 음성 자체는 처리 직후 파기됩니다.

### 반드시 챙길 것

- **외부 API의 학습 사용 차단** — 오디오를 보내는 모델이 그 데이터를 학습에 쓰지 않는 설정인지 확인하고 문서에 명시. 이게 없으면 "저장하지 않습니다"가 반쪽이 됩니다
- **예외 경로는 로드맵으로** — 사건 발생 시 교사가 명시적으로 보존을 선택하는 경로는 보호자 동의서에 별도 항목이 필요합니다. 8일 안에는 만들지 않습니다

## 8.2 두 트랙 — 저장은 동기, 분석은 비동기

```
디벗 MediaRecorder
        │
   서버 수신
        │
        ├─ ① 전사 + 수치 추출 → 저장 [동기 · 필수]
        │     해시 · 서버 시각 · Object Lock
        │     ← 여기서 아이에게 응답 (1~2초)
        │     원본 음성 파기
        │
        ├─ ② 다음 질문 생성 [동기 · 저지연 · 빨강일 때만]
        │
        └─ ③ 감정 추론 [비동기 · 큐]
              세션 종료 후 전체를 한 번에 · 배치 50% 할인
```

감정 추론을 **세션 단위**로 하는 이유: 흐름이 신호이고(색 → "몰라요" → 털어놓음), 호출이 3회에서 1회로 줄고, 비동기라 배치로 넘길 수 있습니다.

## 8.3 DB 구조 — 원본은 불변, 해석은 버전

```
utterance  (불변, append-only)
  id, child_id, session_id, recorded_at(서버시각),
  color, transcript, prosody{...}, sha256, status
  ※ 음성 파일 경로 없음

analysis   (버전 누적)
  utterance_id / session_id, model_name, prompt_version,
  rule_version, emotion_tags, evidence, reasoning, created_at
```

분석을 별도 테이블로 빼야 *"원본은 그대로 있고, 당시 해석은 이 버전이었습니다"*로 답할 수 있습니다.

## 8.4 계층적 기억 — 1년을 4,000토큰으로

| 층          | 내용                           | 생성 시점   |
| ----------- | ------------------------------ | ----------- |
| 원문        | 전사 + 수치. 불변              | 수신 즉시   |
| 일 요약     | 1~2문장 + 태그                 | L1에서 같이 |
| 주 롤업     | 변화 요약, 반복 주제           | 주 1회 배치 |
| 아이 프로필 | 발화 길이 기준선, 관심사, 말투 | 갱신형      |

```
[아이 프로필                400] + [최근 3주 일요약  1,260]
+ [관련 원문 발췌            800] + [루브릭 ← 캐시   1,200]
= 약 3,700 토큰
```

루브릭은 모든 아이에게 동일하니 캐시에 올립니다. **캐시 읽기가 입력가의 10%**입니다.

## 8.5 개인 기준선 — LLM이 아니라 산수

| 측정값      | 방법                                   |
| ----------- | -------------------------------------- |
| 발화 길이   | 음절 수 / 초                           |
| 응답 지연   | 질문 종료 → 첫 발화 (VAD)              |
| 무음 비율   | 전체 대비 무음 구간                    |
| 성량        | RMS, **기기별 정규화 필수**            |
| 어휘 다양성 | type-token ratio                       |
| **색 앵커** | 초록/노랑/빨강 3단계 · **남색은 제외** |

평균·표준편차보다 **중앙값 + MAD**를 씁니다.

```
편차 = 0.6745 × (오늘값 − 중앙값) / MAD
```

**콜드스타트를 정직하게.** 첫 2주는 지표를 띄우지 않고 "기준선 수집 중 9일 / 14일"을 표시합니다. 억지로 띄우면 오탐 폭탄이 됩니다.

## 8.6 후속 질문 중단 정책 — 가장 중요한 기술 설계

에이전트 설계에서 보통 "무엇을 물을지"를 고민합니다. 이 제품에서는 **"언제 묻지 않을지"**가 훨씬 중요합니다.

> **유도 질문은 증거를 파괴합니다.** 아동 학대·학교폭력 사안에서 아동 진술의 신빙성은 유도 질문 여부로 다투어집니다. AI가 *"누가 때렸어?"*라고 물으면 그 시점부터 진술 전체가 오염된 것으로 취급될 수 있습니다.
> **즉 AI가 더 캐묻는 순간, 우리가 만들려던 기록이 무가치해집니다.**

```
물을 것
  · 미해결 스레드 — 이전에 꺼내고 끝나지 않은 주제
  · 색 앵커가 빨강인 이유
  · 아이가 한 약속 — "다음에 얘기해줄래?"

즉시 중단  ← 하드 게이트
  · 신체 위해 · 학대 · 자해 관련 표현 감지
    → 후속 질문 전면 중단
    → "그건 선생님한테 직접 얘기해줄래?"
    → 교사에게 즉시 알림 (최우선)
    → 그 시점까지의 기록을 오염되지 않은 상태로 봉인

  · 남색 선택 → 대화 자체를 시작하지 않음
  · 아이가 회피 신호 2회 → 종료
  · 2턴 도달 → 무조건 종료
```

> **AI가 입을 닫는 것이 기능입니다.**

## 8.7 톤 분석 — 신호처리와 LLM을 나눈다

|               | 무엇                                       | 방법                    |
| ------------- | ------------------------------------------ | ----------------------- |
| **객관 수치** | 무음 길이, 발화 속도, 음량 변화, 응답 지연 | **신호처리 — 결정론적** |
| **해석**      | 위축인지 피로인지 흥분인지                 | LLM (수치 + 전사 입력)  |

수치를 코드로 뽑아 LLM 입력에 함께 넣으면 추론이 수치에 근거를 두게 되고, 교사 화면에 **검증 가능한 근거**를 표시할 수 있습니다.

## 8.8 이상징후 지표는 코드로

4일 연속 하락, 발화 길이 60% 감소, 등교-하교 격차, 2주간 반응 없음 — 전부 **산수**입니다. 코드로 계산하면 비용 0원, 재현 가능, 설명 가능합니다. LLM은 지표가 떴을 때 **"왜"**를 추론할 때만 부릅니다.

## 8.9 이름 치환

```
저장          "민준이가 서연이랑 부딪혔어요"
     ↓ 치환 → API 전송 → 응답 → 역치환
교사 화면      "민준이가 서연이랑 부딪혔어요"
```

매핑 테이블은 학급 단위로 서버에만 둡니다. 개인정보 심사 질문의 절반이 해결됩니다.

## 8.10 지연 예산 — 아이는 3초 이상 기다리지 않는다

| 구간           | 목표     |

| 업로드         | 0.5s     |
| 전사 + 추론    | 1.5s     |

# 9. 기록의 무결성

수기·한글·나이스가 근거로 약한 이유는 형식 때문이 아니라 **고칠 수 있기 때문**입니다.

> **기존 논거** — 녹음 파일이라서 강합니다
> **현재 논거** — **고칠 수 없는 텍스트**라서 강합니다

|           | 수기·한글·메모 | 살핌                      |
| --------- | -------------- | ------------------------- |
| 수정      | 가능           | **불가 (추가 전용)**      |
| 시각      | 작성자 기기    | **서버 시각**             |
| 무결성    | 없음           | **해시 체인**             |
| 열람 이력 | 없음           | **누가 언제 봤는지 남음** |

```
2026-09-19 08:41:07  민준 등교 · 색 빨강 · 4일 연속
2026-09-19 08:44:52  담임 열람 — 브리핑 카드 확인
2026-09-19 09:02:11  담임 조치 — 유니콘 피드백 발송 (지우)
2026-09-19 13:22:30  담임 조치 — 개별 대화 · 메모 첨부
— 이후 수정 불가 · 무결성 해시 a7f3…e1c9 · 서버 시각 기준
```

## 두 가지 증명 용도

|             | 증명 대상                | 무엇이 강한가         |
| ----------- | ------------------------ | --------------------- |
| ⓐ 의무 이행 | 교사가 인지했고 조치했다 | 교사 기록 + 열람 로그 |
| ⓑ 사실관계  | 그날 무슨 일이 있었나    | **아이 발화 전사**    |

아이 발화가 ⓑ에서 강한 이유는 넷입니다.

1. **당사자 진술** — 교사 기록은 이해관계자가 작성한 2차 서술입니다
2. **무목적으로 남았다** — 특정 사건을 위해 만들어진 게 아닙니다
3. **사건 이전에 존재한다** — 사후 진술에 붙는 유도·오염 쟁점이 붙지 않습니다
4. **기준선이 생긴다** — *"아이가 위축됐다"*는 주장에 답하려면 **평소에 어땠는지**가 있어야 합니다

> 무고를 방어한다는 말의 실질은 **평소 상태가 기록으로 존재한다는 것**입니다. 그리고 기준선은 **전원·매일**이어야 성립합니다.

## 표현의 선

| ❌ 쓰지 않는다 | "법정에서 이깁니다" / "무고를 막아줍니다" — 과장이고 법률 자문으로 읽힙니다                |
| -------------- | ------------------------------------------------------------------------------------------ |
| ✅ 이렇게 쓴다 | **"선생님이 매일 무엇을 살폈고 무엇을 확인했는지가, 사후에 고칠 수 없는 형태로 남습니다"** |

현장에서 "녹음이 가장 확실하다"는 인식이 있지만 확정된 법리는 아닙니다. 발표에서는 **"현장에서는 이미 녹음이 가장 확실한 기록이라고 여겨집니다"**라고 사실만 전하고, 우리 답은 형식이 아니라 **성질**을 바꾸는 것이라고 말합니다.

# 11. 데모 설계

## 두 가지 전환

**① 방문자를 관찰자가 아니라 대상으로 세운다.** 이 제품의 핵심 루프는 사람 아무에게나 작동하고, 방문자 전원이 한때 그 교실의 아이였습니다.

**② 3주 누적을 3턴으로 압축한다.** 3주치 데이터의 가치는 "첫 인상과 실제가 다르다"인데, 그건 한 번의 대화 안에서도 일어납니다.

## 다섯 단계 — 이탈 지점 없음

```
① 색 고르기 ─ 5초
     "지금 마음이 어떠세요?"  초록 · 노랑 · 빨강 · 남색

② 말한다 ─ 20초
     고른 색에 맞춰 AI가 먼저 말을 겁니다

③ AI가 되묻는다 ─ 30초
     "괜찮다고 하셨는데 3초 정도 멈추셨어요. 뭐가 걸리세요?"

④ 당신의 카드 ─ 20초
     표면 / 그 아래 / 근거(3.1초 침묵, 성량 -30%)
     "첫 마디만 남겼다면 '괜찮음'으로 기록됐을 겁니다"

⑤ 같은 카드가 28개 ─ 25초
     "먼저 살펴야 할 아이 세 명을 골라주세요"
     → 예린이를 놓칩니다
     → "그런데 오늘 한 마디 돌려줄 아이는 이 세 명입니다"
```

**⑤의 마지막 줄이 새로 추가됐습니다.** 방문자가 자기 실패를 확인한 직후에 유니콘 열을 보여주면, 이 제품이 경보기가 아니라 **돌봄 도구**라는 게 전달됩니다.

## 왜 투어가 아닌가

| 단계                | 실제 제품 기능인가     |
| ------------------- | ---------------------- |
| ① 색 신호등         | ✓ 아이 앵커와 동일     |
| ② ③ 발화·후속 질문  | ✓ 동일한 엔진          |
| ④ 카드 생성         | ✓ 동일한 포맷·프롬프트 |
| ⑤ 학급 격자 + 두 열 | ✓ 아침 브리핑 그 자체  |

다섯 단계 전부 제품의 실제 기능입니다. **투어를 만들 필요가 없어 개발 부담이 줄어듭니다.**

## 첫 화면에서 하면 안 되는 것

로그인 · 빈 대시보드 · **첫 화면 마이크 권한 요청** · 긴 소개 문단 · 로딩 스피너.

| ---- | --------- | ------------------------------------------------------------------------------------------------------------------------ |
| 1    | 개별 교사 | 디벗이 있는 3~4학년 담임. 학교 승인 없이 시작 가능한 최소 단위. 교사 커뮤니티가 유통 경로                                |
| 2    | 학교      | 학년 전체가 쓰면 전출입·인계 시 기록이 이어짐. **담임이 바뀔 때 아이에 대한 이해가 리셋되지 않는 것**이 학교가 사는 이유 |
| 3    | 교육청    | 학생 정서·행동 지원, 교권 보호는 이미 편성된 예산. 연 1회 설문을 연속 측정으로 대체                                      |

최소 판매 단위는 **학급 하나**입니다. 전국 초등 학급 약 12만 개 중 **3~4학년이 약 4만 학급**이고, 실질 모수는 **디벗 보급률**입니다. 보급이 확대되면 모수가 자동으로 늘어납니다.

## 확장 축

> 이 구조는 교실에서 시작했습니다. 하지만 **사람이 사람을 살피는 모든 일**에 적용됩니다.
> 조건은 넷입니다 — 반복해서 살피고, 그 살핌이 기록되지 않고, 나중에 소명해야 하고, 살피는 사람은 시간이 없다.
> 교사, 팀장, 면접관, 요양보호사가 모두 이 조건 안에 있습니다. **다음 적용면은 조직의 1:1입니다.**

## 온라인 투표 20%

투표는 **본선 20팀에 드는 데만** 영향을 주고 대상 결정에는 **0%**입니다. 목표는 "이기기"가 아니라 **"죽지 않기"**입니다. 그리고 모수는 일반인이 아니라 **교사 약 50만 명**이고, 교사 커뮤니티는 결집력이 훨씬 높습니다.
