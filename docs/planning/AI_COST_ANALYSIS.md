>
> 기획안의 비용표는 **"학급 30명 · 학교/교육청이 지불"** 을 전제한다(학생 1인당 월 550원).
> 이 문서는 전제가 다르다 — **불특정 다수가 쓰고, 비용은 우리가 전액 부담한다.**

## 1. 결론

**세션 1회에 약 $0.0035 (5원).** 수천 명 규모 데모에서도 10만원을 넘지 않는다.

| 데모 이용자 | 세션(1인 2회) | 총 비용 |
|---|---|---|
| 500명 | 1,000 | $3.5 (약 5천원) |
| 1,000명 | 2,000 | $7 (약 1만원) |
| 5,000명 | 10,000 | $35 (약 5만원) |
| 10,000명 | 20,000 | $70 (약 10만원) |

**단가는 문제가 아니다. 상한 없이 여는 것이 문제다** (§4).

## 2. 세션 1회 내역

| 단계 | 모델 | 계산 근거 | 비용 |
|---|---|---|---|
| 첫 질문 | **고정 템플릿** | 호출 없음 | **$0** |
| STT ×2 | `gpt-4o-mini-transcribe` $0.003/분 | 30초 × 2회 = 1분 | $0.0030 |
| 대화 LLM ×2 | `gpt-4o-mini` $0.15 / $0.60 per 1M | 입력 800 + 출력 150 토큰 | $0.0004 |
| 감정 추론 ×1 | `gpt-4o-mini` + Batch 50% | 입력 1,000 + 출력 200 토큰 | $0.0001 |
| | | **합계** | **$0.0035** |

### 비중

```
STT          $0.0030   ████████████████████  86%
대화 LLM     $0.0004   ██                    11%
감정 추론    $0.0001   ▌                      3%
```

**LLM 벤더를 바꿔도 11% 안에서 움직인다.** 아낄 곳은 STT 하나다.

## 3. STT 선택지

| 제공자 | 단가(분) | 비고 |
|---|---|---|
| **Groq** Whisper Large v3 Turbo | **$0.00067** | 약 4.5배 저렴. **하루 2,000 요청 무료** |
| OpenAI `gpt-4o-mini-transcribe` | $0.003 | 기존 스택과 같은 벤더 |
| Deepgram (batch) | $0.0037 | |
| OpenAI Whisper | $0.006 | |
| Google Chirp | $0.016 | 가장 비쌈 |

> **싼 것이 답이 아니다.** 한국어 아동 발음을 못 알아들으면 전사가 쓰레기가 되고,
> 그 위에 얹는 감정 추론도 같이 무너진다. **한국어 아동 발화 샘플로 실측 비교**한 뒤 정한다.
>
> 참고로 국내 연구에서 **아동은 음성에서 정서를 알아보는 능력 자체가 성인보다 낮다**
> (정상청력 아동 65.79% vs 성인 88.49%). 아동 음성은 기계에게도 어려운 입력이다.
> 정부가 구축한 **AI-Hub 아동 음성 데이터**를 정확도 비교에 쓸 수 있다.

## 4. 진짜 위험 — 단가가 아니라 폭주

§2 의 계산은 **"아이가 30초씩 두 번 말한다"** 는 전제다. 데모에서는 안 지켜진다.

| 위험 | 대응 | 상태 |
|---|---|---|
| 마이크 켜두고 방치 | **녹음 60초 하드 캡** | ✅ `MAX_RECORDING_MS` 구현됨 |
| 한 사람이 수십 번 반복 | 세션 수 제한 (IP·브라우저 단위) | ⬜ 미구현 |
| 장난으로 계속 녹음 | 일일 총량 상한 → 초과 시 텍스트 입력으로 전환 | ⬜ 미구현 |
| 프롬프트 주입으로 긴 출력 유도 | **출력 토큰 상한 200** | ✅ `max_output_tokens` 구현됨 |

**상한이 없으면 단가가 싸도 사고가 난다.** 60초 캡 하나만 빠져도
한 사람이 10분을 녹음하면 그 세션만 20배가 된다.

## 5. 비용을 줄이는 수단 (적용 여부)

| 수단 | 효과 | 상태 |
|---|---|---|
| 첫 질문 고정 | 세션당 LLM 1회 절감 | ✅ 적용 |
| 출력 토큰 상한 200 | 출력 비용 고정 | ✅ 적용 |
| 2턴 상한 | 호출 수 상한 | ✅ 적용 (게이트) |
| 감정 추론 **Batch API** | 해당 호출 50% | ⬜ 연결 시 적용 |
| **프롬프트 캐싱** | 입력 $0.15 → $0.075 | ⬜ 연결 시 적용 |
| 회피 시 조기 종료 | 불필요한 턴 제거 | ✅ 적용 (게이트) |

프롬프트 캐싱은 **시스템 프롬프트가 매번 같기 때문에** 그대로 효과를 본다.
대화 LLM 입력의 대부분이 시스템 프롬프트다.

## 6. 권장

1. **LLM은 OpenAI `gpt-4o-mini`.** 환경변수·코드·문서가 이미 OpenAI 모양이고,
   비중이 11%라 벤더를 바꿔 얻을 실익이 없다.
   (기획안은 대화에 Claude Sonnet 급을 지정했는데, 그 근거는 **"3초 예산"** 이었다.
   그건 모델 급의 문제지 벤더 문제가 아니다.)
2. **STT는 Groq vs OpenAI 실측 비교 후 결정.** 4.5배 차이라 규모가 커지면 의미가 생긴다.
3. **감정 추론은 Batch API.** 실시간일 필요가 없다 (기획안 §8.2: *"비동기 · 큐 · 배치 50% 할인"*).
4. **데모 모드 상한을 먼저 넣는다.** 세션 수 제한과 일일 총량은 아직 없다.
5. 모델은 **환경변수로** 둔다 (`CHAT_MODEL`). 결정이 바뀌어도 코드를 고치지 않는다.

## 7. 사업 단계에서 달라지는 것

데모가 아니라 실서비스가 되면 기획안의 계산으로 돌아간다.

> 음성을 저장하지 않아 스토리지 비용이 사실상 사라졌습니다. 학생 1인당 **월 550원**입니다.
> **교사 개인 월 1만원으로는 원가가 안 맞습니다.**
> **학급당 월 3~5만원(학교·교육청 단위)** 이 손익 구간입니다.

이 문서의 관심사는 **그 전까지 우리가 부담하는 구간**이다.
